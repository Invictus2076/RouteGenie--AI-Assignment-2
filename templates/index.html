RouteGenie

Your AI travel companion. Configure your trip and click Generate Optimal Plan. RouteGenie builds real PDDL files, runs Goal Stack planning, and sequences a conflict-free itinerary.

Stack: Python (STRIPS engine) · PDDL 1.2 domain & problem files · Flask REST API · Goal Stack backward-chaining · Knowledge Base of 8 world destinations
🧠 Knowledge Base
8 destination cities with hotels, attractions, flight routes, and costs encoded as typed PDDL predicates.
⚙️ STRIPS Engine
8 operators (BUY_FLIGHT, TAKE_FLIGHT, BOOK_HOTEL, CHECK_IN, ARRANGE_TRANSPORT, VISIT_ATTRACTION, EXPERIENCE_CULTURE, COMPLETE_TRIP) with PRE/ADD/DEL lists.
📚 Goal Stack
Backward-chaining planner pushes goals, decomposes into sub-goals, finds applicable operators, and produces a forward-executable plan.
📄 PDDL Output
Every plan generates a valid PDDL 1.2 domain + problem file downloadable and runnable with Fast Downward or any PDDL planner.
